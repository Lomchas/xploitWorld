# M6.1 · Expediente Vanta

Abre **Exchange → Tienda → Herramientas de práctica** para añadir licencias de 0 BTC. Las herramientas añadidas aparecen en **Inventario → Biblioteca de práctica**. Cada ficha enlaza con su expediente de Historia.

En **Historia → Prácticas**, prepara el expediente para añadir las herramientas que falten. Abre las pestañas de evidencia, responde las preguntas y comprueba tus decisiones. Una práctica aprobada desbloquea la siguiente y permite guardar el informe en `~/trabajo`. Vincula tu cuenta en **Exchange** para recuperar licencias y progreso en otro navegador.

Cada módulo presenta evidencia sintética preparada para el juego. Los informes, nombres de equipos, dominios y registros pertenecen al Expediente Vanta.
